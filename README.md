# KVS-OYMS 2.0 — Demo Website

Independent front-end prototype for PM SHRI Kendriya Vidyalaya Ordnance Factory Medak.

## Current phase
- Responsive public homepage inspired by government portal layouts.
- Common login page with six role choices.
- Demo dashboard preview and Super Administrator profile / navigation preview.
- No Supabase connection and no real authentication yet.

## Demo use
Open the site and select a role in Login. Demo values are illustrative only. Do not enter real student information or real passwords.

## Next phase
After design review: connect Supabase Auth, database, role permissions, row-level security, account freeze/unfreeze approval workflow and audit logs. Do not store passwords in application tables or expose service-role keys in browser code.

## Important
This is an independently developed school portal prototype, not an official KVS application. All demo data is fictional.
